- [homelab-as-code](https://github.com/klercke/homelab-as-code):
    My homelab, built in OpenTofu and Ansible from a collection of YAML files.
    Includes a Grafana monitoring stack, authoritative PowerDNS zones, split-horizon HTTP routing with Caddy, and more.
- [nixcfg](https://github.com/klercke/nixcfg):
    NixOS and Home Manager config for my machines, using flake-parts in the dendritic style.
- [d0cuments](https://github.com/klercke/d0cuments):
    My technical blog where I write about whatever project I've been working on, or whatever topic I've been obsessed with lately.
- [ProtoBot](https://github.com/klercke/ProtoBot):
    One of my oldest projects still in use, a Discord bot (re)written in Rust for my server.
- [ProtoChess](https://github.com/klercke/ProtoChess):
    A chess game and engine written in Rust.
    Unfinished and on pause for now.
- [WiCyS-RIT-CTF-2023](https://github.com/klercke/WiCyS-RIT-CTF-2023):
    Challenges I wrote for RIT WiCyS's CTF in 2023 based around a Rust C2 server that embeds data in ICMP packets.
- [website](https://github.com/klercke/website):
    This site, including the browser shell and SSH version.
